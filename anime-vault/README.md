# ANIME VAULT · 番剧硬盘档案馆

给多块移动硬盘做「永久目录快照」的本地工具。盘拔下来之后，依然能看到里面有什么、占多大、是哪个汉化组的什么规格。

## 启动

双击 `start.bat`（会自动打开浏览器，默认 http://127.0.0.1:8777）。
只需要 Python 3.9+，无第三方依赖，数据全部存在本机 `data/vault.db`。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 记录硬盘 | 左下「记录新硬盘」选盘符 →（可选）指定文件夹 → 起名 → 扫描。几秒到十几秒完成，只读目录、不改文件 |
| 全部硬盘总览 | 左侧「全部硬盘」：跨盘总数、每块盘的容量与健康、跨盘容量排行、全库规格分布；「番剧墙」也会合并所有盘 |
| 目录快照 | 每次扫描的结果永久保存在本地，硬盘拔掉后照样能浏览、搜索 |
| 硬盘命名 | 概览页「重命名」，只改快照里的名字，不动硬盘卷标 |
| 健康 / 寿命 | 读取 SMART：通电时长、温度、重试次数、厂商状态，给出 0-100 健康指数与剩余寿命估算 |
| 容量分析 | 每部番的体积、占整盘百分比、Top 排行、按来源/编码/清晰度/字幕的体积分布 |
| 番剧识别 | 从文件夹名解析片名、汉化组、BD/WEB 来源、HEVC/H.264、1080p、10bit、FLAC/AAC、简繁内封/外挂/简体/繁体、季数、集数范围 |
| 封面海报 | 多图源：Bangumi → AniList → 文件夹里的竖版图；「更新封面」批量补，单部可「更换封面」从候选里挑 |
| 搜索 | 顶部搜索框（快捷键 `/`），可切换「仅当前盘 / 所有硬盘」 |
| 目录浏览 | 按体积排序，逐层进入，显示大小与占盘比例 |
| 打开位置 | 详情页「在资源管理器中打开」，硬盘在线时直接定位到该文件夹 |

## 识别逻辑说明

文件夹名会被拆成「括号标签」和「正文」两部分：正文作为片名，标签按关键词归类为汉化组与规格。
文件夹名里缺的规格（例如 `[BDrip] NEW GAME! S01 [7³ACG]` 没有编码信息）会继续读里面视频文件名补齐（`x265.FLAC` → HEVC / FLAC）。
`ASSx2` / `SRTx2` 视为「简繁内封」，`简繁外挂` / `CHS&CHT` / `JPSC` 等都有对应映射。

识别不准时：详情页「编辑信息」可改标题、汉化组、封面，改动会被标记为手动并**在重新扫描后保留**。

## 扫描范围（指定文件夹）

一个盘可以记多个「扫描目录」：整个盘，或者某个子文件夹。

- **整个硬盘**：根目录下的每个文件夹算一部番剧。适合番剧都摊在根目录的盘。
- **指定文件夹**：只扫这个文件夹，它下面的每个子文件夹算一部番剧。适合 `E://动画//2024春//xxx` 这种分层存放的盘。
- 同一块盘可以「整个硬盘」+「某个合集文件夹」各记一份，互不覆盖；概览页会用标签列出所有扫描目录和各自番剧数。
- 扫子文件夹时，会自动补上上级目录的虚拟节点，所以「目录」页还是能从盘符一层层点进去。
- 「重新扫描」会把这块盘下所有扫描目录依次重扫一遍。

> 注意：如果一个目录被两个扫描目录同时覆盖（比如整个盘 + 它里面的子文件夹），同一批番剧会被统计两次。

## 关于封面

自动匹配依次尝试：

1. **Bangumi**（中文名友好，国内可直连）——拿不到图时会自动降级
2. **AniList**（免密钥，海报是高清竖版，用罗马音/英文名检索，中文别名也支持一部分）
3. **文件夹里的图片**——只认竖版、且不在 `Scans/` 里的图，横版 banner、光盘扫描图会被跳过（宁缺勿错）

三种都不理想时，在番剧详情点「更换封面」：

- 顶部列出两家的全部候选海报，点一下即替换
- 下方列出该文件夹里的所有图片，含尺寸，可直接选
- 也支持「粘贴任意图片地址」和「上传本地图片」
- 还给了「在 Bangumi 搜索」「在弹弹play 搜索」的跳转，找到图后复制图片地址贴回来即可

> 弹弹play 的开放接口需要 AppId + 签名（个人申请），所以没有直接接入，只提供搜索跳转 + 贴图。手动设置的封面会被标记为 manual，重新扫描也不会被覆盖。

## 数据位置

- `data/vault.db` — 所有硬盘快照与番剧信息（SQLite，可直接备份）
- `data/covers/` — 本地海报缓存
- 换电脑或重装时，整个 `anime-vault` 文件夹拷走即可

## 备注

- Bangumi 匹配需要联网；无网络时识别结果与本地海报仍然可用，只是部分封面会显示占位图。
- 「健康指数」是基于 SMART 的经验估算，仅供参考，不能替代专业检测工具。
